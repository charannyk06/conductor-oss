# Conductor OSS

Local-first AI agent orchestrator built with Rust + Next.js.

## Before You Start

- Read `CLAUDE.md` for architecture and conventions.
- Run `cargo test --workspace` before making changes.
- Check `CONDUCTOR-TAGS.md` for task tagging conventions.
- Branch from `main`.
- Use conventional commit messages.

## Code Style

### Rust

- Use `thiserror` for library errors and `anyhow` for binaries.
- Use tokio, axum, and sqlx with SQLite.
- Prefer `Arc<RwLock<T>>` or `DashMap` for shared state.
- Avoid `unwrap()` in library code.

### TypeScript

- Use Bun >= 1.2.
- Use Next.js 16 App Router.
- Keep library code ESM-only.
- Do not use default exports in library code.

## Architecture Constraints

- Keep the workflow local-first.
- Keep runtime defaults ttyd-first.
- Keep persistence SQLite-only.
- Keep Conductor agent-agnostic.
- Keep board state Markdown-native in `CONDUCTOR.md`.
